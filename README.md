プロダクトの中核アーキテクチャは、すべて Google のクラウド技術・AI 技術で構成されています。

| Google 技術 | プロダクトでの役割・活用場面 | 選定理由（Own the Why） |
| :--- | :--- | :--- |
| **Google Cloud Run** | Web サービス全体のサーバーレス実行基盤（Next.js App Router） | 東京リージョン（`asia-northeast1`）での低遅延稼働、コンテナによる完全な可搬性、自動スケーリング。 |

## 🎯 プロダクトの特徴と主な実動機能

すべての機能はモックや偽装ではなく、Firestore・Cloud Storage・Vertex AI と接続して実際に動作します。

1. **放射状スキルツリー**
   - 中央の「あなた」から、生命科学・情報・語学・経験の 4 分野へ実線が伸びるビジュアルツリー。
   - 審査済み（実線枠・蜂蜜色背景）、審査中（破線枠・薄背景）、次に伸ばせる枝（点線枠・プロジェクトの募集役割から動的補完）を識別表示。
   - 枝ボタンを押すと、スキルの名前、レベル、審査状態、何をしてきたかの説明、審査日、根拠件数を表示。
2. **在籍校だけでは実現できないプロジェクト公募 ＆ 1 クリック応募・提唱者承認**
   - 「自大学内の専門だけでは不足している理由」を必須として提唱・公募。
   - 学生は希望するロールを選んで動機を送信。提唱者がスカウト画面から承認すると即座にメンバーへ合流。
3. **チャット発言からのタスク化と進捗管理**
   - プロジェクト全体のリアルタイムチャットに加え、発言の横にある「📌 タスク化」ボタンから担当者・期日付きでタスクを作成。
   - タスク一覧画面で未着手・進行中・完了の状態をリアルタイムに更新管理。
4. **Cloud Storage による安全なファイル共有**
   - チームの資料や成果物を Cloud Storage（東京リージョン、1ファイル20MB上限）へアップロード。
   - 閲覧時は 15 分間限定の Signed URL を動的発行し、安全にダウンロード・プレビュー。
5. **🤖 Vertex AI Gemini によるプロジェクト進行度測定**
   - 目標・メンバー・タスク・直近のチャット発言から、Gemini が達成度（%）、順調な点、ボトルネック、次の一歩のアドバイスを診断。
   - 「なぜその進捗率なのか」の客観的根拠（Why）を可視化。
6. **🤖 Vertex AI Gemini による AI 引継ぎ要約**
   - メンバーの交代や一時離脱の際、対象メンバーの発言や活動記録から Gemini が申し送り要約（現状ステータス、決定事項、残タスク）を自動生成。1 クリックで全体連絡へ共有可能。
7. **🎓 Vertex AI Gemini による AI ガクチカ下書き生成**
   - プロジェクト活動の実績から、就職活動で活用できる「学生時代に力を入れたこと（ガクチカ）」の下書き（背景・役割・課題と工夫・成果・学び）を自動生成。画面上で加筆・修正・コピーが可能。
8. **⭐ メンバー相互評価と星評価・関わったプロジェクト一覧の表示**
   - 終了したプロジェクトのメンバー同士で、「貢献」「信頼」「協調」「発信」の 4 項目を星 1〜5（★）で評価しコメントを保存。
   - プロフィールやメンバー一覧カードに総合平均星、4 項目の平均、評価件数を表示。関わったプロジェクト一覧（プロジェクト名、役割、期間、状態）も動的に確認可能。
9. **🛡️ 運営の管理画面（審査員向け全機能開放）**
   - スキル申請審査、プロジェクト公開承認、利用者の管理（メールアドレス伏字保護 `s***@gmail.com`）、学校・スキルマスター、お知らせ配信、追記専用監査ログなど、運営業務の全機能を網羅。

## 🛡️ 審査用の設定（管理画面の特別開放）

審査員の方々に HIVE の運営・管理機能を網羅的にご確認いただくため、本番環境において以下の審査用設定を適用しています。

1. **ログイン者全員への管理画面機能の開放**:
   - 審査員に運営の全機能（スキル申請審査、プロジェクト公開承認、利用者の管理、学校・スキルマスター、操作記録など）を体験いただくことが目的のため、Google 認証でログインしたすべてのアカウントが管理画面のすべての機能・API 操作を利用できるようにしています。
   - 画面左サイドバーの「運営の管理画面へ」リンクから、1 クリックで運営管理画面（`/admin`）へアクセスできます。
2. **登録データの安全性（完全なサンプルデータ）**:
   - 登録されている学生（10名）およびプロジェクト、会話履歴、相互評価はすべてデモ用のサンプルデータであり、実在する人物のメールアドレス等の個人情報は一切入れていません（管理画面上でもメールアドレスは伏字 `s***@gmail.com` で保護表示されます）。
3. **本来の運用アーキテクチャ**:
   - 本来の運用では、運営の印（admin ロールおよび `ADMIN_EMAILS` 環境変数）を持つアカウントのみが管理画面を利用できる厳格なアクセス制御設計となっています。

## 💻 動かし方の概要（Local Development）

### 前提条件
- Node.js 20.x 以上
- Google Cloud プロジェクト設定（Cloud Run、Firestore、Cloud Storage、Vertex AI 有効化）
- Google Cloud SDK（ADC: `gcloud auth application-default login` 設定済み）

### セットアップ手順

```bash
# 1. 依存パッケージのインストール
npm install

# 2. マスターデータと学生・デモプロジェクトの投入
npx tsx scripts/seed-master.ts
npx tsx scripts/seed.ts
npx tsx scripts/seed-ten-students.ts
npx tsx scripts/seed-demo-projects.ts
npx tsx scripts/seed-demo-history.ts

# 3. 開発用ローカルサーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開くと Web サービスが起動します。

### 本番ビルドとデプロイ

```bash
# 型チェックとプロダクションビルド
npm run build

# Cloud Run へのデプロイ
gcloud run deploy hive \
  --source . \
  --region=asia-northeast1 \
  --allow-unauthenticated \
  --max-instances=3
```
